# Introduction to PHP 7: Console Scripts and Web Services

📘 **Access the course documentation:** [https://stahe.github.io/en-php7-juillet-2019/](https://stahe.github.io/en-php7-juillet-2019/)

---

This project offers a collection of PHP 7 console scripts illustrating various aspects of the language and its ecosystem.

## Repository Contents

The examples cover the following topics:
- **Language Structures**
- **File Access**
- **Database Access**
- **Internet Access**

## Web Approach

Web programming is approached here from the perspective of **web services**. In this context, we define a "web service" as any application that produces plain text (data servers), as opposed to web page servers that generate a mix of HTML, CSS, and JavaScript.

### Key Concepts Covered
The project explores fundamental web concepts used in traditional programming:
- HTTP protocol
- JSON or XML response formats
- Session management
- Authentication
